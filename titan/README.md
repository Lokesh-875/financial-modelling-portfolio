**BSE Code: 500114 | Sector: Jewellery, Watches & Eyewear**

## Overview
Titan Company Limited is an Indian fashion accessories company (part of the Tata Group) manufacturing jewellery (Tanishq), watches, and eyewear (Titan Eyeplus). This project builds a full 3-statement financial model and DCF valuation to estimate intrinsic value.

## Valuation (DCF — FCFF Method)

| Assumption | Value |
|---|---|
| WACC | 10.87% |

| Output | Value |
|---|---|
| PV of FCFF (explicit period) | ₹6,359 Cr |
| PV of Terminal Value | ₹87,532 Cr |
| Value of Operating Assets | ₹93,891 Cr |
| **Equity Value per Share** | **₹734.27** |
| Current Market Price | ₹4,584.40 |

**Finding:** Free cash flow to firm is *negative* in the first two forecast years — reinvestment rate exceeds 150% of NOPAT — before turning positive from FY27 onward. This reflects Titan's aggressive store expansion and working capital needs (gold inventory), not a modelling error. The DCF-implied intrinsic value is roughly 5.2x below market price, consistent with the market pricing in long-term growth durability that a 5-year explicit forecast can't fully capture.

- Interpreting a negative-FCFF period correctly instead of treating it as an error
